# Lessons

- When the user explicitly tunes exposure and a player's displayed overall, keep sampling weights separate from attributes, retain derived overall, and document product tuning honestly. Apply rarity to every sampling pool and measure complete-draft exposure, not just the featured slot. An active tab keeps its loaded bundle; explain save invalidation before publishing a new rule/catalog version.

- A successful request to the Tailscale IP from the host or Orca browser does not validate a phone-to-host route. Check peer status, compare reachability with another peer and observe incoming traffic. A peer marked online can still have an unreachable tunnel; do not claim its VPN is disconnected from a ping timeout alone.

- In an NBA identity task, “original logos” can mean the authentic franchise marks. After the explicit correction, use official sources and distinguish franchise-logo vintage from historical roster year. Do not substitute invented emblems while implying the identity request is satisfied. A public CDN URL is provenance, not an open redistribution license; preserve a usable name fallback for remote assets.

- Expanding a catalog changes the frequency of recognizable stars even when sampling stays uniform. Measure recognition separately from overall and measure complete-run outcomes against the actual opponent pool before calling a draft balanced. Competitive mechanics must be grounded in the official product, not similarly named clones or unconfirmed guarantees.

- Apply explicit scope corrections to the data eligibility, research queues, opponents, tests and documentation together. NBA-only male scope supersedes the earlier international/WNBA mix; do not keep excluded content active because it was already researched. Validate `nbaExperience` and explicit male eligibility rather than trusting a broad basketball catalog.

- Draft presentation must follow the latest product decision: six comparable offers visible as a mobile grid, with style and sourced career context that make the choice meaningful. Recheck the live experience rather than relying only on structural card counts.
- A correct overall formula does not prove editorial calibration. When a legend's number feels wrong, audit the source-backed attributes and cross-role anchors before changing weights or inflating a target rating.

- Localhost is a secure context even over HTTP and can mask unsupported APIs on the delivered network URL. Generate run seeds with `crypto.getRandomValues`, which works in insecure contexts; do not require `crypto.randomUUID`. Validate the actual delivered HTTP origin, including Play and save/reload, before claiming browser flow works.
